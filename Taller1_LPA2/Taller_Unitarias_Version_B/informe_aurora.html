Como reproducir la evaluacion

Desde una terminal ubicada en la carpeta del proyecto:

python -m pip install -r requirements.txt
python -m pytest --cov=src --cov-branch --cov-report=html

Consulta el reporte oficial con detalle de lineas o vuelve al README para ver las instrucciones de VS Code.
